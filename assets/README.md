# Arcade brand assets

Use **Omarchy Font** for the Omarchy Arcade title and short display headings on social cards and promotional artwork. Use a simple supporting face for taglines, small labels and longer copy. The native app's controls continue to follow its existing typography and theme settings.

## Omarchy Font

- Author: Mark Cuda.
- Source: [markcuda/Omarchy-Font](https://github.com/markcuda/Omarchy-Font).
- Pinned revision: `cddbc3eaa86f982e6301c162d6ad25555411f508` (font 2.1).
- Vendored unchanged as [fonts/Omarchy-Font.ttf](fonts/Omarchy-Font.ttf); upstream filename: `Omarchy Font.ttf`.
- Git blob SHA: `da0fbc7114ec89a3e2088d22bdd7da4fa6cf1e07`.
- [MIT licence and copyright notice](fonts/LICENSE.txt).

The font is unicase: lowercase input renders as capitals. Its upstream credits identify Omarchy with DHH and 37signals and the original Delta Corps Priest 1 FIGlet lettering with CoSMiC cHiLD. Mark Cuda's font is a fan project.
