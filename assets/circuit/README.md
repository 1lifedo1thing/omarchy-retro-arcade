# Circuit artwork

`table.png` is the production background plate derived with OpenAI Image Generation from the Omarchy Circuit concept approved by the user in this project conversation. The classic Windows screenshot was a composition/reference input, not a bundled game resource. Original orbital illustration, materials and cabinetry were generated for this project.

The plate deliberately omits moving balls, flippers, central branding, game counters and most functional text. CircuitView renders those from actual game state, and uses the exact official Omarchy wordmark from assets/brand separately. Static mechanical artwork and decorative lighting remain in the plate.

Artwork supplied for this project is distributed under the repository MIT licence; official Omarchy branding remains subject to its own attribution and rights, documented in assets/brand/README.md.

## Central wordmark adaptation

Source: `assets/brand/omarchy-wordmark.svg`, SHA-256 `be58c4b721a666f23fb9e756a39cbd62868c6717e36d4beed8fe8035bae54222`. Original viewBox: 4131 × 950, fill #9ece6a. `native/BrandWordmark.h` preserves all 211 source rectangles exactly. CircuitView scales uniformly to 180 × 41.394 design pixels, centred at (562, 520), with no crop, recolouring, background or added text. Transparent negative space reveals the board. Standard 1152 px and compact 900 px native renders are the destination previews. No source pixels or geometry are modified.
