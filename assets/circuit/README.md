# Circuit artwork

`table.png` is the production background plate derived with OpenAI Image Generation from the Omarchy Circuit concept approved by the user in this project conversation. The classic Windows screenshot was a composition/reference input, not a bundled game resource. Original orbital illustration, materials and cabinetry were generated for this project.

The plate deliberately omits moving balls, flippers, central branding, game counters and most functional text. CircuitView renders those from actual game state, and uses the exact official Omarchy logo from assets/brand separately. Static mechanical artwork and decorative lighting remain in the plate.

Artwork supplied for this project is distributed under the repository MIT licence; official Omarchy branding remains subject to its own attribution and rights, documented in assets/brand/README.md.
