# Omarchy Chess

A native chess app for Omarchy, powered by Stockfish. Play offline against the computer or share the board with a friend.

Development is in progress. See the implementation branch / pull request for the first playable preview and installation instructions.

Independent community project, not an official Omarchy distribution component.
