- Tom's default language for new projects is Rust. Omarchy Chess must be implemented in Rust, including the native GUI and application logic. Do not introduce a Python runtime or Python build steps.
- Propose another implementation language only for a concrete requirement and get agreement before changing the stack.
- Keep autonomous judgement calls and material trade-offs in DECISIONS.md.
- Use feature branches and pull requests. Preserve user changes and existing review history.
- Verify real Stockfish integration and native packaging. Clearly distinguish automated/headless evidence from a real Omarchy desktop acceptance pass.
