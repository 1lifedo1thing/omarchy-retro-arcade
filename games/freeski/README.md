# FreeSki

An original SkiFree-inspired downhill skiing game planned for Omarchy Arcade.

**Status: project setup only. Milestone 1 is awaiting design discussion.**
There is no playable FreeSki, Cargo crate, shelf entry or launch command yet.

The target is endless Free Ski with optional creature pursuit and five authored
Slalom courses, hosted in Arcade's existing native window and package.
