# FreeSki asset provenance

Status: no game artwork or audio has been added.

Create original skier geometry, snow, trees, rocks, ramps, course marks, creature
design and sound. Reuse the existing shared cabinet materials around the playing
surface. Preserve all other games' approved assets.

For every shipped asset or code-generated visual/sound set, record its path,
creator/source, creation method, licence, modifications and attribution needs.
For generated assets also record the tool and relevant creation brief. Keep
source files and reproducible generation instructions where practical.

New original project work follows GPL-3.0-or-later. Preserve separate notices for
any permitted reused materials and include them in installed-package provenance.
