# Project rules

- Use branches and PRs; do not merge or publish a release without user direction.
- The default Omarchy table must use upstream physics and components. Do not substitute native/PinballModel.cpp or a new physics engine to work around missing resources.
- Author new table data and scoring rules explicitly. Do not claim Space Cadet table or mission fidelity.
- Keep classic resource loading available explicitly; never bundle proprietary original resources.
- Keep test claims specific: default-table tests must execute the original engine with authored data.
- Preserve official Omarchy artwork unchanged.
