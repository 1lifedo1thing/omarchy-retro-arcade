# Omarchy Arcade v0.3.0

Minesweeper joins Arcade: thirteen games in one native window, with offline play,
local saves and a bundled Stockfish engine for computer Chess.

## New in this release

- Minesweeper: Beginner (9×9, 10 mines), Intermediate (16×16, 40 mines) and Expert
  (30×16, 99 mines). The first reveal and its neighbours are safe; empty areas
  expand automatically. Flags, chording, mouse and keyboard controls are included.
- Exact board, timer and per-difficulty records survive closing and reopening.
  Restored games start paused. Invalid or future save files remain untouched.
- The board, counters, controls and dialogs follow the desktop palette. Palette
  and fontconfig monospace font changes reload while playing.

Circuit Pinball, Solitaire, Scram, Invaders, Chess, Stack, Snake, Bubble, Blast,
2048, Shatter and Tanks remain included. FreeSki is planned for v0.4.0 and is not
in this release. Minesweeper has no audio; random boards can require guessing.

## Install and upgrade

Download the player package and SHA256SUMS from the same v0.3.0 release:

```sh
sha256sum --ignore-missing --check SHA256SUMS
sudo pacman -U ./omarchy-retro-arcade-0.3.0-1-x86_64.pkg.tar.zst
omarchy-retro-arcade --version
```

The version command reports `Omarchy Arcade 0.3.0`. Open Arcade from the desktop
menu, or run `omarchy-retro-arcade --game minesweeper`. Use arrows to move, Space
to reveal, F to flag, C to chord and Esc to pause. Ctrl+H returns to Arcade.

Close Arcade and back up saves before upgrading. Existing games retain their
save locations and schemas; Minesweeper uses a separate
`$XDG_STATE_HOME/omarchy-retro-arcade/minesweeper.json` (normally
`~/.local/state/omarchy-retro-arcade/minesweeper.json`). Pinball retains settings
and records, not unfinished tables. See [save locations](../MIGRATION.md).

Pacman owns updates. To downgrade, close Arcade and install the previous package
with `sudo pacman -U /path/to/previous.pkg.tar.zst`. Downgrading does not reverse
save-schema changes; retain the matching save backup and newer files. v0.2.0
does not use Minesweeper's save. Uninstall with `sudo pacman -R
omarchy-retro-arcade`; retain state directories if you want to keep progress.

## Verification and limits

Publication requires the versioned commit's engine, native and Arch jobs to pass.
BUILD.txt records that source commit, tree, build run and architecture; SHA256SUMS
covers the complete asset set. The corresponding-source archive includes the
application, pinned Stockfish source and evaluation network.

Automated coverage includes thirteen-game switching, mouse layouts, Minesweeper
keyboard/pause/save protection, live palette/font reload, package installation
and same-package reinstall/save preservation. These Linux/Xvfb checks do not
establish live Omarchy/Wayland acceptance, a full old-version upgrade matrix,
audio/gameplay acceptance for the collection, or aarch64 compatibility.

Target: Omarchy 4 / Hyprland; binary: x86_64. This is a community app, not an
official Omarchy package. The GitHub release description links the final CI run
and records publication status; this file describes the prepared release.
