# Omarchy Arcade v0.3.0

Minesweeper is here. Arcade now has thirteen games in one native window.

- **Three ways to lose an afternoon.** Beginner (9×9, 10 mines), Intermediate (16×16, 40 mines) and Expert (30×16, 99 mines). Your first reveal and its neighbours are safe. Empty areas open automatically, with flags and chording for the rest.
- **Pick up where you left off.** Your board, timer and records save locally. Reopened games start paused, so the clock waits for you.
- **It fits your desktop.** The board, counters and dialogs follow your theme. Change the palette or monospace font while playing and Minesweeper updates with it.

Play with the mouse or keyboard: arrows to move, **Space** to reveal, **F** to flag, **C** to chord and **Esc** to pause. **Ctrl+H** takes you back to Arcade.

All twelve existing games are still here, with offline play and bundled Stockfish for computer Chess. FreeSki is planned for **v0.4.0**.

Minesweeper is silent, and some boards need a guess.

## Get playing

Download the x86_64 package and `SHA256SUMS` from this release. Close Arcade and back up your saves before upgrading.

```sh
sha256sum --ignore-missing --check SHA256SUMS
sudo pacman -U ./omarchy-retro-arcade-0.3.0-1-x86_64.pkg.tar.zst
omarchy-retro-arcade --game minesweeper
```

You can also launch Arcade from the desktop menu. `omarchy-retro-arcade --version` reports `Omarchy Arcade 0.3.0`.

Existing games keep their save locations and schemas. Minesweeper saves to `$XDG_STATE_HOME/omarchy-retro-arcade/minesweeper.json`, normally `~/.local/state/omarchy-retro-arcade/minesweeper.json`. Pacman handles updates. To roll back, close Arcade and run `sudo pacman -U /path/to/previous.pkg.tar.zst`. Keep the matching save backup and newer files: downgrading does not undo save-format changes. v0.2.0 ignores Minesweeper's save. To uninstall, run `sudo pacman -R omarchy-retro-arcade`; keep the state directories to retain progress.

The release commit passed all three [CI jobs](https://github.com/tcballard/omarchy-retro-arcade/actions/runs/35151032807): engine, native and Arch. Checks cover thirteen-game switching, mouse layouts, Minesweeper keyboard controls, pause/save protection, live theme/font reload, package installation and save preservation across a same-package reinstall.

Live Omarchy/Wayland testing, the full old-version upgrade matrix, collection-wide audio/gameplay acceptance and aarch64 support remain unverified. This x86_64 release targets Omarchy 4 / Hyprland and is a community app.
